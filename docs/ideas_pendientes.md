# Ideas pendientes para agregar al proyecto

Este archivo registra ideas de funcionalidades futuras para evaluar, priorizar y convertir luego en tareas de desarrollo.

## Buzon de sugerencias

- Permitir que empleados envien sugerencias desde la app o portal web.
- Posibles categorias: mejora operativa, clima laboral, seguridad, beneficios, otros.
- Permitir envio anonimo o identificado, segun configuracion.
- Panel administrativo para ver, responder, cambiar estado y exportar sugerencias.
- Estados sugeridos: nueva, en revision, aceptada, rechazada, implementada.

## Linktree de gente

- Crear una pagina tipo directorio para centralizar links utiles de cada persona o sector.
- Posibles datos: foto, nombre, puesto, sector, telefono interno, email, links importantes.
- Puede servir como perfil interno para colaboradores, responsables o referentes.
- Evaluar permisos para definir que informacion ve cada rol.

## Programa de buenas practicas

- Modulo para que empleados presenten ideas de mejora o buenas practicas.
- Flujo posible: presentacion de idea, evaluacion, aprobacion, seguimiento e implementacion.
- Permitir adjuntos, comentarios y estado de avance.
- Posibles campos: titulo, problema detectado, propuesta, beneficio esperado, sector impactado.
- Panel para destacar ideas aprobadas o implementadas.

## Talles de ropa

- Registrar talles de ropa laboral por empleado.
- Posibles campos: remera/chomba, pantalon, campera, calzado, observaciones.
- Historial de entregas de indumentaria.
- Alertas o reportes para compras por talle y sector.
- Exportacion para proveedor o administracion.

## Notas de priorizacion

- Definir si estas funciones son solo web, solo mobile o ambas.
- Validar roles necesarios: empleado, RRHH, administrador, responsable de sector.
- Revisar si corresponde auditoria para cambios sensibles.
- Diseñar primero el modelo de datos antes de construir pantallas.
